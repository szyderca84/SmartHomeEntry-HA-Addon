  # SmartHomeEntry Home Assistant Add-on                                                                                                                                            
                                                                                                                                                                                    
  Official Home Assistant add-on for [SmartHomeEntry](https://smarthomeentry.com) - secure remote access to your Home Assistant without VPN or port forwarding.
                                                                                                                                                                                    
  ## Installation 
                                                                                                                                                                                    
  Add this repository in Home Assistant:      
                                                                                                                                                                                    
  1. Home Assistant → Settings → Add-ons → Add-on Store
  2. Menu (⋮) → Repositories                                                                                                                                                        
  3. Add URL: `https://github.com/szyderca84/SmartHomeEntry-HA-Addon`
  4. Find "SmartHomeEntry Agent" in the store and click Install

  ## About                                                                                                                                                                          
                                                                                                                                                                                    
  [SmartHomeEntry](https://smarthomeentry.com) is a zero-config remote access platform for smart home systems. The agent connects to our relay and allows you to access Home
  Assistant from anywhere, without opening ports on your router.
